## 📱 如何查看自动生成的报告

所有自动化任务的报告都会保存在 Qoder 的对话历史中，使用 `merged` 输出模式，意味着：

1. **所有报告在同一个对话中**
   - 不会创建新的对话
   - 便于查看历史记录和趋势

2. **查看方式**：
   - 打开 Qoder
   - 找到对应的自动化任务对话
   - 按时间顺序查看所有报告

3. **报告格式**：
   - 每日报告：简洁明了，适合快速浏览
   - 每周报告：结构化分析，包含图表和建议
   - 月度报告：专业格式，便于存档和决策

## ️ 任务管理

### 查看任务状态
```bash
# 在 Qoder 中使用 qoder_cron list 命令
```

### 临时禁用任务
如果某天不需要执行某个任务，可以临时禁用：
```bash
qoder_cron disable --task-id <任务ID>
```

### 重新启用任务
```bash
qoder_cron enable --task-id <任务ID>
```

### 手动触发任务
如果想立即执行某个任务（不等定时触发）：
```bash
qoder_cron run --task-id <任务ID>
```

### 删除任务
如果不再需要某个任务：
```bash
qoder_cron remove --task-id <任务ID>
```

## 🔔 通知设置（可选）

如果你希望在任务执行时收到通知，可以：

1. **Qoder 桌面通知**：
   - 确保 Qoder 桌面应用已安装
   - 开启系统通知权限

2. **Telegram 通知**（需要额外配置）：
   - 在服务器上设置 Telegram Bot
   - 修改自动化任务的 prompt，添加发送消息步骤

3. **邮件通知**（需要额外配置）：
   - 配置 SMTP 服务
   - 修改任务 prompt，添加发送邮件步骤

## ❓ 常见问题

### Q1: 任务没有按时执行怎么办？
A: 检查以下几点：
- Qoder 是否在运行
- 网络连接是否正常
- 服务器 SSH 是否可达
- 查看任务执行历史是否有错误

### Q2: 如何修改任务执行时间？
A: 使用 `qoder_cron update` 命令修改 schedule 表达式

### Q3: 报告太长不想看怎么办？
A: 
- 每日报告很简洁，建议每天都看
- 周报和月报可以只看"核心数据"和"建议"部分
- 详细内容可以存档，需要时再查阅

### Q4: 能否增加更多检查项？
A: 可以！告诉我你想增加什么检查项，我可以修改任务的 prompt

### Q5: 如果服务器重启了怎么办？
A: 
- 自动化任务会继续尝试执行
- 如果 SSH 连接失败，会在报告中显示错误
- 你需要手动重启服务器上的 quantkit 进程
